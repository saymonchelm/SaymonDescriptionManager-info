# SaymonDescriptionManager

SaymonDescriptionManager is a private internal application used by the owner of the Saymon Allegro seller account.

The application integrates with the Allegro REST API to retrieve and manage the owner's own sales offers and assist with maintaining product descriptions.

The application is intended exclusively for internal business use and is not offered as a public service or made available to third parties.

## Purpose

The application uses authorized access to the Allegro REST API for:
- retrieving the owner's sales offers,
- reading account information required for authorization verification,
- managing and updating the owner's offer descriptions.

## Access

Access to the application is restricted to its owner. Authentication with Allegro is performed through the official Allegro OAuth authorization process.
